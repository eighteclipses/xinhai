## 想送给同好的一份小礼物

我很喜欢 Persona 里的一种感觉：明明只是读了书、和人聊了天，回头看，却发现自己已经悄悄往前走了一点。

于是我想，能不能把这种感觉放进平时学习的桌面里？

心海共学就是这样一点点做出来的。它有专注计时，也有待办、习惯、笔记和复习卡。你可以放一首喜欢的歌，选一个愿意待着的场景，先把今天的一件小事做完。完成之后，让音符响一下，让今天留下点痕迹。

它不会替你学习，也没有什么坚持几天就能改变人生的承诺。我只是希望，在某个不太想开始的晚上，它能让你愿意多坐下来一会儿。

## 现在能做什么

| 想做的事 | 心海共学里有什么 |
|---|---|
| 今天先开始一点 | 待办、优先级、计划日期，从任务直接进入专注 |
| 给学习留出时间 | 番茄钟、正计时、暂停与完成记录 |
| 看见一点成长 | 音符反馈，学识、意志、表达、体贴、灵巧五个维度 |
| 让习惯按自己的节奏来 | 打卡、历史回看、拖动排序、删除与撤销 |
| 别把学过的都忘了 | 本地 Markdown 笔记、Obsidian 仓库入口、间隔复习卡 |
| 回头看看这一天 | 日历整合任务、专注、打卡、日记和安排 |
| 给桌面一点陪伴感 | 音乐歌单、本地音乐导入、背景与人物调整 |

还有一个留在特定日子里的小彩蛋。这个就先不剧透了。

### 先把目标缩小一点

![待办：从一件小事开始](docs/images/todo.jpg)

“复习五道错题”比“今天一定要努力”更容易开始。任务和专注可以接在一起，投入过的时间会留下记录。

### 断了一天，也能继续

![习惯：拖动排序与历史回看](docs/images/habits.jpg)

习惯可以换顺序，也可以删掉不再适合自己的。删掉一个习惯，不会把过去的打卡和成长一起抹掉。

### 学到的东西，放在自己手里

![知识库与复习](docs/images/review.jpg)

笔记是本地 Markdown 文件，复习卡就在知识库里。先试着回答，再翻开答案，让下一次复习有个约定。

## 0.2.9：让音乐和桌面更顺手

![可拖动的 P3R 风格音乐列表](docs/images/music-panel-blue.jpg)

随身听可以拖，展开后的音乐列表也可以。按住白色标题区域移动窗口，歌曲区域照常上下滚动；下次打开会记住位置。歌曲和「导入与歌单」分开显示，搜索、播放控制、本地导入与网易云公开歌单链接都在。

这次参考 P3R 菜单的白色斜切标题、编号和白色选中条，重新整理了音乐窗口。人物主题切换后，时钟、随身听、图标和列表配色一起变化。

![由加莉主题下的音乐列表](docs/images/music-panel-yukari.jpg)

场景已扩展到 22 个，也可以导入自己的背景。自动轮换支持自定秒数或分钟数、随机或顺序，以及专注／壁纸欣赏等使用范围。总攻击演出有独立开关，默认关闭；关闭后直接查看成长，喜欢的壁纸切换动画仍然保留。

Windows 已验证鼠标和触摸拖动、位置记忆及多尺寸布局。Android 0.2.9 已完成构建和签名检查，本次实机验收仍待完成；不把桌面验证当作平板验收。[完整更新记录](docs/版本记录.md)

## 关于下载，先说明白

**这里是公开的项目展示仓库，目前没有公开安装包，也不是可以直接构建的完整源码仓库。**

当前开发版本为 **0.2.9**，Windows 安装包与 Android APK 在作者的私有仓库留存。因为使用的第三方角色、音乐和背景等内容还需要逐项整理使用范围，公开下载暂时没有放出来。后续如果提供公开版本，会在这个仓库写清楚。

## 想了解得更细一点

- [项目说明书](docs/项目说明.md)（[PDF 排版版](docs/项目说明书.pdf)）：0.1.9 发布时的功能与架构说明；新增功能以本页及更新记录为准。
- [素材来源与鸣谢](CREDITS.md)：按实际收集记录保留作者与来源。
- [反馈一个问题](https://github.com/eighteclipses/xinhai/issues)：告诉我版本、操作步骤、原本期待的结果和实际发生的情况。

Windows 使用 Electron、React、TypeScript、Zustand 和 SQLite；Android 使用原生 WebView 容器与本地 SQLite，复用界面和共享逻辑。基本学习工具可以离线使用；只有主动配置云模型评分时，相关日记内容才会发送到用户自己选择的服务。

这是非官方同人作品，与 SEGA / ATLUS 没有官方隶属或授权背书。Persona 相关角色、音乐与游戏画面归各自权利人所有。软件实现与资料整理使用了 AI 辅助；第三方素材的署名不代表再分发授权。
