# 心海共学 · 0.2.34 源码快照

这份代码整理自个人版 0.2.34，提供 Windows Electron 应用和 Android 横屏 WebView 容器。包含专注计时、待办、习惯、日历、五维成长、日记回响、Markdown 知识库、复习卡片、本地音乐、自定义外观、完整备份与局域网同步的实际实现。

[完整个人安装包](https://github.com/eighteclipses/xinhai/releases) · [构建步骤](BUILD.md) · [检查记录](docs/source-validation.md) · [文件清单与 SHA-256](docs/source-manifest.json) · [问题反馈](https://github.com/eighteclipses/xinhai/issues)

源码包标识为 `0.2.34-source.0`，与安装包的 `0.2.34` 分开。源码版使用独立资料目录和 Android 包名，不附带游戏素材，也不会自动发现作者或使用者已有的个人学习库。它并非空壳，默认使用仓库内可直接构建的中性示例画面。

## 代码结构

| 目录 | 内容 |
|---|---|
| `src/main/` | Electron 主进程、SQLite、评分、知识库、备份和同步服务 |
| `src/preload/` | 桌面界面与主进程之间的接口 |
| `src/renderer/` | React 页面、专注与成长演出、外观及播放器 |
| `src/mobile/` | Android WebView 的接口适配 |
| `src/shared/` | 两端共享的类型、计时、奖励、备份与同步规则 |
| `android/app/` | Android 原生容器、文件桥接、SQL 策略和系统提醒 |
| `scripts/` | 合成数据检查；原生依赖检查单独运行 |

0.2.34 进一步修复设置表单可读性、简化专注提示并补全版本足迹；本补丁未做新的实体平板验收。当前代码包含统一可拖缩的专注面板、后台等待/继续行为、累计 25 分钟音符与集中结算、自定义入口搜索、笔记改名/删除、日记删除、学习分类、日历明细和全量任务统计。专注有效秒数照常记录，旧分数不回算。

备份数据库为 v3，包含 22 张表；旧 v1/v2 快照经过严格迁移后奖励账本为空，不给旧记录补算新奖励。同步发出 v3 数据，双方需使用支持这一协议的版本；接收旧 v1/v2 数据不会回填新奖励贡献。演出回执只影响待收下状态，不重复发分。

## 中性素材与完整个人版的区别

源码内置三张由 SVG 代码绘制的示例背景、示例播放器外壳、项目自有图标，以及空音乐/语音清单；默认关闭立绘、语音和自动播放，使用系统字体回退。日期装饰不依赖游戏图片，专注完成预览使用中性静态画面。

完整个人版的 21 个场景和 29 张原始立绘（其中三位角色、14 张可选）的路径、尺寸、来源和校验信息保留为元数据；相关图片、视频、音乐、语音、字体和播放器皮肤均不在 Git 源码中分发。无素材的角色不会出现在可选人物库或快速导航中，防止坏图入口。参见 [素材清单](docs/media-boundary.md)。开发者若添加有权使用的人物素材，需要相应维护可用 ID 清单；仅有来源记录不代表获得使用许可。

可以通过现有界面导入自己有权使用的背景和本地音乐。商业专用构建、商业资源、发布密钥、作者学习资料和设备诊断未包含在源码目录。共享代码保留部分 `COMMERCIAL_EDITION` 兼容分支；源码的两个构建入口将它固定为 `false`，不提供商业目标。

## 构建

需要 Node.js 20 或更新版本。进入本目录后：

```sh
npm ci
npm run typecheck
npm test
npm run check:source
npm run build
npm run build:mobile
```

桌面开发使用 `npm run dev`，Windows 打包使用 `npm run dist`。Android 还需 JDK 17、Gradle 8.7、SDK 35 和 Build Tools 35.0.0；详细步骤及原生依赖说明见 [BUILD.md](BUILD.md)。

Windows 明确使用独立的 `xinhai-source` 用户/会话目录和“心海学习库-源码版”默认知识库。Android 发布包名为 `com.xinhai.study.source`，调试包名为 `com.xinhai.study.source.qa`。源码示例包不能当作原个人包升级，也没有作者的签名密钥。

## 资料与联网边界

学习记录保存在本机。日记的本地规则分析不访问模型；个人模式保留自带 API Key 的可选模型分析，只有主动选择该模式时，当前正文才会发送给保存的服务，并可能产生费用。公开提示词只包含评分规则与合成示例，不含作者的私人日记判例。模型配置与密钥不进入源码、完整备份或局域网同步。

局域网同步默认关闭，需主动配对。完整备份是未加密文件，可能包含正文、草稿和附件；请自行保管。网易云歌单相关功能需要联网，第三方服务的可用性与使用条件由其提供方决定，仓库没有附账号或登录凭据。

历史“即时拍”调试服务默认关闭。只有同时设置 `XINHAI_ENABLE_SNAPSHOT=1` 与 32 到 256 字节的随机 `XINHAI_SNAPSHOT_TOKEN` 才启用；仅监听 `127.0.0.1:7391`，请求必须携带 `Authorization: Bearer <token>`，且没有通配 CORS 或正文日志。不要把令牌提交到仓库。
