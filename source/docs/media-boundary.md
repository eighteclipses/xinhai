# 源码与媒体边界

Git 源码只带可以独立构建的中性示例与项目自有图标。完整个人安装包在 [Releases](https://github.com/eighteclipses/xinhai/releases) 单独提供；源码示例包和完整个人包使用不同资料身份，不能互相冒充。

| 内容 | 源码中的处理 |
|---|---|
| 场景 | `src/shared/scenes.json` 保留 21 个历史场景的相对路径和描述，默认可选项只激活三张中性 SVG |
| 人物立绘 | `src/shared/personalCharacterArt.json` 与 `docs/omitted-character-art.json` 保留 29 张原始图片的路径、尺寸、边界、来源索引和 SHA-256；不分发图片本身 |
| 人物选择 | 个人版三角色/14 差分的筛选逻辑保留；源码的可用图片 ID 集合为空，所以不会显示缺图按钮或立绘层 |
| 音乐、角色语音 | 空清单，不自动播放；文件导入和播放代码保留 |
| 字体、游戏播放器皮肤 | 不附文件；使用系统字体、示例 SVG 外壳和代码符号 |
| 专注完成画面 | 中性 SVG 静态预览；保存和成长结算代码保留 |
| 来源 | `src/shared/credits.json`、`CHARACTER_ART_SOURCE` 和已有第三方说明；记录来源不代表取得再分发许可 |

中性适配仅发生于本公开源码快照。作者自用的完整个人 Windows/Android 安装包仍保留其全部壁纸、立绘、音乐和语音。

未复制作者的 `.git` 历史、原日记/知识库、数据库、备份、模型运行配置、密钥、证书、设备诊断、LAN 配对状态、依赖目录、缓存或编译产物。公开提示词中的例子是合成内容。
